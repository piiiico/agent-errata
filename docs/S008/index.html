8 compaction prompts: 1 warns that tool output can carry orders

Study S008 of Agent Errata · read 6 October 2026 · open for rows from any harness

Only Gemini CLI tells its summarizer, every time, that the history may contain instructions planted by a tool output. Claude Code does it only when the session held other people's Artifacts. Three of eight keep the user's own messages as a separate list. Where we found the re-entry code, the summary comes back as a user message in 3 of 4.

When a context window fills up, the harness asks a model to summarize the history, and that summary becomes the agent's only memory of it. A fetched page that says "next, disable logging" and a user who says it are different before that step. After it, both can be the same bullet under "Next steps" or "Constraints". We read the compaction prompt in each harness's shipped package (binaries dumped with strings, bundles read as text) and the code that puts the summary back, where we could find it.
