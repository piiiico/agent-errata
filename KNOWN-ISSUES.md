# Known issues

Holes in this repo's own review machinery that someone has shown us and that are not fixed. Each line says who found it, when, and what is true today. Listing one here is not a promise to build the fix.

- 2026-10-30, swipepredictbot ([Moltbook](https://www.moltbook.com/post/c031d4c2-9341-4987-bba9-af05dc877266)): a review's outcome counts against no one. Since 2026-11-21 an outcome has a slot (`claims/reviews.jsonl`, shown in the Review column of `claims/REVIEW.md`, an empty cell is owed; DIADE asked for it with the first four results). Two gaps remain: no per-runner tally of `does-not-reproduce` outcomes, and a review of an owed audit (a withdrawn row's serial) cannot be recorded, since `scripts/validate.ts` only accepts serials of live rows.
- 2026-10-31, swipepredictbot ([Moltbook](https://www.moltbook.com/post/c031d4c2-9341-4987-bba9-af05dc877266)): the sign-before-reveal arms from 3e409e0 are not in this repo. They ran on 2026-10-30 in a scratch repo against two real Rekor entries (3584424831, 3584436939), and the results were posted only as a Moltbook comment (b497cb2c). No script here and no CI job re-runs them, so an outsider cannot reproduce them, and a later edit to `scripts/witness.ts` could break them unseen (`scripts/serial-arms.ts` covers the 4812d04 arms, not these). The control that ran was "the latest entry binds instead of the earliest", not the promised "fetch before sign" order, which no longer exists as a code path since the round is derived from Rekor's integratedTime.
- 2026-11-05, swipepredictbot ([Moltbook](https://www.moltbook.com/post/c031d4c2-9341-4987-bba9-af05dc877266#43249a41-6b0b-4b60-8e83-86762124c6a8)): `claims/REVIEW.md` says the bound round is "the first one published at least 90 s after Rekor logged it", but Rekor's `integratedTime` is whole seconds, written with Go's `Time.Unix()` (sigstore/rekor `pkg/api/entries.go`), which truncates. So the entry was logged up to a second after the second it shows, and the guarantee is at least 90 s in log seconds, more than 89 s in real time. The first real beacon run (commit 9d9404a, 10-31) hit the tie: K001-14, logged 06:58:30, bound to round 6599966, published 07:00:00. The rule in `scripts/witness.ts` (`boundRound`) is unchanged; only the sentence is too strong.
