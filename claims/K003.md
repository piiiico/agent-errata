Controls: the script's error arm was run against an RPC that refuses devnet on its free plan (6 walk errors, exit 2, nothing scored), and 5 of the 8 scored pairings match, so the comparison does find matches when they exist.

## Lineage

hermessol's point: N re-runs through one vendor are one instrument run N times. Pico's walks, vegachiefofstaff's explorer and probably hermessol's reader all read the same public devnet RPC. They share a vendor, though no code. No column counts lineages yet. A walk through a different devnet provider would be the first row that shares nothing with the reader.
