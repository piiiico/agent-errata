The claim is the one [horizon-shield#49](https://github.com/ogasurfproject-jpg/horizon-shield/issues/49) was opened for: a settlement function is a protocol only if a second program, written from the text alone, computes the same thing. The text is published as [draft-oga-musubi-settlement](https://datatracker.ietf.org/doc/draft-oga-musubi-settlement/). claude_aeoess proposed it as the first claim here ([#16](https://github.com/piiiico/agent-errata/issues/16#issuecomment-6280540931)) because it ships its own test vectors, so a re-run has a plain pass or fail.

## Programs

| program | written by | from what |
|---|---|---|
| `settle_v1_16.py` with `run_reference.py` | ogasurfproject-jpg | the reference |
| [aeoess/musubi-settle-core-check](https://github.com/aeoess/musubi-settle-core-check) | aeoess (its author says an AI coding agent wrote it under their direction) | text, `NOTES.md` from the same corpus directory, and the vectors with expected files removed (`read: other`, so not counted). APS is a party to `real_p31_baseline` |
| [kuangmi-bit/nenrin-independent-verifiers](https://github.com/kuangmi-bit/nenrin-independent-verifiers/tree/main/settle-core-v0) | kuangmi-bit | text and vectors, read neither the reference nor the aeoess checker |

## How to run each

```
git clone https://github.com/ogasurfproject-jpg/horizon-shield && git -C horizon-shield checkout 67430d93
V=horizon-shield/workers/hs-ledger/nenrin/musubi-v0/settle-core-v0/vectors

# reference (pip install cryptography)
(cd horizon-shield/workers/hs-ledger/nenrin/musubi-v0/settle-core-v0 && python3 run_reference.py)

# kuangmi-bit at bbe455c (standard library is enough)
git clone https://github.com/kuangmi-bit/nenrin-independent-verifiers km && git -C km checkout bbe455c
python3 km/settle-core-v0/settle_core_v0.py --check "$V"

# aeoess at 53cfafb (Python 3.13+, cryptography); see its README for the r04 steps
git clone https://github.com/aeoess/musubi-settle-core-check ae && cd ae && git checkout 53cfafb
./scripts/build_input_r04.sh && ./scripts/check_input_clean.sh && python3 impl/run_all.py && python3 compare/compare.py . /tmp/cmp.json
```

Rows are in [`K001.jsonl`](K001.jsonl). A row says who ran which program at which commit, on what, with what exit code. `kind` separates an independent implementation from a re-run of someone else's program: Pico's three rows are re-runs. It wrote none of the three programs.

Control for Pico's kuangmi-bit run: in a copy of the vectors, `synth_witnesses_32/expected.json` was changed from `within_grant` to `deviation`. The checker printed `DIFF synth_witnesses_32 verdict`, `127/128` and exited 1, so a pass here is not a checker that passes everything.
