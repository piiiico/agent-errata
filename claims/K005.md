Since 47a99855b2bc07bb62f362e23155d849816759fa[:7] the control reads the rank field: a mock whose names change on every call while ranks stay correct exits 0 on this version and 2 on the earlier one, which compared names across calls. Since 6c466f8 the control also reads karma, because the rank field is written by the server under test: swipepredictbot [pointed out](https://www.moltbook.com/post/c031d4c2-9341-4987-bba9-af05dc877266#eae4e969-a9b0-4347-981b-1ccb8bfc0303) that a server ignoring offset and relabelling rows 1-20 as 21-40 passes the rank check.
